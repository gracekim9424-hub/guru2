# 다녀옴! (by GURU2 Android-1)
국내 여행 장소를 추천받고, 방문한 장소의 사진과 메모를 지도에 기록하는 안드로이드 여행 기록 애플리케이션입니다.


## 로그인 안내

본 애플리케이션은 Room 로컬 데이터베이스를 사용하므로
처음 실행하는 기기에는 등록된 계정이 없습니다.

회원가입 화면에서 이메일과 비밀번호를 등록한 후 로그인해 주세요.


## 주요 기능

- 회원가입 및 로그인
- 네이버 지도 기반 장소 검색
- 지역별 명소·맛집·놀거리 추천
- 여행 날짜, 장소, 사진, 메모 기록
- 여행 기록을 지도 마커로 표시
- 여행 기록 조회 및 삭제
- 친구 목록 추가 및 삭제
- 검색 지역의 날씨 예보 확인

## 개발 환경

- Android Studio
- Kotlin

- Navigation Compose

- GitHub


## 데이터 관리 방식

기본 장소 정보는 `places.json` 파일에서 불러와 Room 데이터베이스에 저장합니다.

사용자가 작성한 회원 정보, 여행 기록, 사진 URI 및 친구 정보는
기기 내부의 Room 로컬 데이터베이스에 저장됩니다.

따라서 앱을 삭제하거나 앱 데이터를 초기화하면 저장된 정보가 삭제될 수 있습니다.
